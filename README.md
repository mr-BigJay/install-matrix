# نصب آسان Matrix برای خودت و دوستات 🇮🇷

با این پروژه می‌تونی روی **سرور خودت** یه پیام‌رسان راه بندازی؛ تقریباً شبیه کاری که با Jay Messenger انجام دادیم. اسمش **Matrix / Synapse** هست و با **Element** توی مرورگر کار می‌کنه.

**برای نصب لازم نیست برنامه‌نویس باشی.** فقط باید VPS، دامنه و چندتا رکورد DNS داشته باشی و دستور پایین رو اجرا کنی. اسکریپت خودش بیشتر کارها رو انجام می‌ده. ساخت حساب مدیر هم با یک دستور ساده انجام می‌شه.

> ⚠️ **نسخه اولیه / آزمایشی:** این اسکریپت هنوز روی سرور تازه به‌صورت End-to-End آزمایش میدانی نشده. بهتره اول روی VPS خالی امتحانش کنی. برای نگهداری پیام‌های حساس، قبل از استفاده جدی حتماً امنیت و بکاپ رو بررسی کن.

## قبل از نصب چی لازم داری؟

| چی؟ | توضیح ساده |
| --- | --- |
| 🖥️ **یه VPS تازه** | **Ubuntu 24.04**، ترجیحاً **۴ گیگ RAM** و **۲ هسته CPU**؛ حداقل نزدیک ۲ گیگ RAM و ۱۲ گیگ فضای خالی |
| 🌍 **IP عمومی ثابت** | یه IPv4 عمومی که به VPS وصل باشه |
| 🌐 **یه دامنه** | مثلاً `mychat.ir`؛ لازم نیست ۴ تا دامنه بخری، **۴ تا زیردامنه** از همین یکی درست کن |
| 🔑 **دسترسی sudo** | باید بتونی داخل سرور دستورهای مدیریتی اجرا کنی؛ کنسول اضطراری VPS هم در دسترست باشه |
| 📶 **اینترنت و DNS** | هر چهار زیردامنه باید **قبل از نصب** به IP همون سرور وصل شده باشن |
| 🔌 **پورت‌های باز** | TCP: `80`، `443`، `7881`؛ UDP: `50000-50100`؛ SSH خودت رو هم باز نگه دار |
| 📦 **دسترسی برای دریافت نرم‌افزار** | مخزن‌های Ubuntu، GitHub (برای خود اسکریپت)، و یکی از Docker Hub یا آینه‌اش؛ همچنین `ghcr.io` برای JWT |

### اون ۴ تا زیردامنه دقیقاً چی هستن؟

فرض کن دامنه‌ات `mychat.ir` و IP سرورت `203.0.113.10` باشه (**این IP فقط مثال است**). توی پنل DNS دامنه‌ات چهار رکورد **A** بساز:

| اسم رکورد | آدرسی که ساخته می‌شه | کاربرد |
| --- | --- | --- |
| `matrix` | `matrix.mychat.ir` | خود سرور Matrix / Synapse |
| `chat` | `chat.mychat.ir` | سایت پیام‌رسان Element |
| `admin` | `admin.mychat.ir` | پنل ساخت و مدیریت کاربرها |
| `call` | `call.mychat.ir` | سرویس تماس صوتی و تصویری |

**مقدار هر چهار رکورد A باید IP واقعی VPS خودت باشه.** اسم‌ها رو هم اگه دوست داشتی، موقع نصب می‌تونی عوض کنی (مثلاً `echo`، `msg`، `mngmnt` و `fideo`). رکورد AAAA اشتباه/قدیمی هم نگذار که کاربرها از مسیر IPv6 اشتباه برن.

> گواهی HTTPS رو Caddy به‌صورت خودکار می‌گیره. برای همین باید دامنه‌ها از اینترنت قابل دسترس باشن و پورت‌های 80 و 443 بسته نباشن. دریافت گواهی در بعضی شبکه‌ها/ارائه‌دهنده‌ها ممکنه با محدودیت روبه‌رو بشه.

## نصب با یک خط 🚀

اول با SSH وارد **VPS تازه Ubuntu 24.04** بشو. اگر `curl` نداری، یک بار `sudo apt update && sudo apt install -y curl` رو اجرا کن.

**همین یک خط رو توی ترمینال بزن:**

```bash
tmp=$(mktemp) && curl -fL --retry 3 https://raw.githubusercontent.com/mr-BigJay/install-matrix/main/install.sh -o "$tmp" && sudo bash "$tmp"; rm -f "$tmp"
```

این روش اول اسکریپت رو دانلود می‌کنه، بعد اجراش می‌کنه. بهتره قبل از اجرا، [کد نصب‌کننده](./install.sh) رو هم ببینی؛ داری بهش دسترسی مدیریتی سرورت رو می‌دی.

موقع نصب، فقط به چندتا سؤال جواب بده: دامنه اصلی، آدرس چهار زیردامنه (اگر همون پیش‌فرض‌ها خوبه Enter بزن)، و IP سرور. **رمزهای فنی و توکن‌ها خودکار و تصادفی ساخته می‌شن.**

صبر کن تا ایمیج‌ها دانلود و سرویس‌ها اجرا بشن. مدت نصب به سرعت VPS و اینترنتش بستگی داره.

### بعد از نصب

آدرس‌ها رو توی مرورگرت باز کن:

- **پیام‌رسان:** `https://chat.mychat.ir`
- **مدیریت کاربرها:** `https://admin.mychat.ir`
- **سرور Matrix:** `https://matrix.mychat.ir`
- **سرور تماس:** `https://call.mychat.ir` (خودش سایت چت نیست؛ پشت‌صحنه تماس کار می‌کنه)

برای **ساخت اولین حساب مدیر**، روی VPS این دو دستور رو بزن:

```bash
cd /opt/install-matrix
sudo docker compose exec synapse register_new_matrix_user -a -c /data/homeserver.yaml http://localhost:8008
```

اسم کاربری و رمز حساب مدیر رو وارد کن. برای بقیه کاربرها می‌تونی از پنل مدیریت یا همین ابزار (بدون `-a`) استفاده کنی.

**کاربرها چطور همدیگه رو پیدا کنن؟** داخل Element گزینه New Chat رو بزنن و نام نمایشی یا نام کاربری همدیگه رو جستجو کنن. جستجوی همه کاربران محلی توی این نصب فعاله؛ این یعنی اسم و شناسه کاربران برای بقیه کاربران قابل پیدا شدنه.

## مخصوص اینترنت ایران

بعضی VPSها نمی‌تونن از Docker Hub ایمیج بگیرن. نصب‌کننده اول رجیستری اصلی رو امتحان می‌کنه و اگر نشد، از **`docker.novin.cloud`** به‌عنوان راه جایگزین استفاده می‌کنه. برای سرویس JWT فعلاً به **`ghcr.io`** هم نیاز داریم.

**نکته امنیتی:** `docker.novin.cloud` آینه شخص ثالثه، نه رجیستری رسمی پروژه‌ها. اگر بهش اعتماد نداری، قبل از نصب دسترسی به رجیستری اصلی رو فراهم کن یا ایمیج‌ها رو خودت با Digest معتبر بررسی کن. اسکریپت به‌تنهایی اصالت آینه رو تضمین نمی‌کنه.

ممکنه توی بعضی اپراتورها/شبکه‌ها تماس صوتی و تصویری به خاطر NAT یا محدودیت UDP خوب وصل نشه. **برای این شرایط احتمالاً باید سرور TURN با TLS هم راه‌اندازی کنی**؛ این نسخه هنوز TURN نصب نمی‌کنه. اتصال WebRTC رو حتماً با دو دستگاه و ترجیحاً دو اینترنت مختلف آزمایش کن.

اگه GitHub از روی VPS باز نمی‌شه، فایل `install.sh` رو از یک دستگاهی که دسترسی داره دانلود و با `scp` به VPS انتقال بده؛ بعد `sudo bash install.sh` رو اجرا کن. اگر Ubuntu/Docker/GHCR هم مسدود باشن، باید مشکل دسترسی به منابع نصب رو جداگانه برطرف کنی.

## دقیقاً چی نصب می‌شه؟

**PostgreSQL 16** برای دیتابیس، **Synapse 1.162.0** برای سرور Matrix، **Element Web** برای ظاهر پیام‌رسان، **Ketesa** برای مدیریت کاربران، **LiveKit 1.13.4** و **lk-jwt-service 0.8.0** برای تماس، و **Caddy** برای HTTPS.

کانتینرهای داخلی روی localhost یا شبکه داخلی Docker هستند. فقط وب و پورت‌های رسانه LiveKit عمومی می‌شن. ثبت‌نام آزاد حساب‌ها خاموشه و رمزهای دیتابیس، سرویس تماس و توکن‌ها تصادفی ساخته می‌شن.

این نسخه فقط برای **Ubuntu 24.04 روی x86_64** آماده شده و برای **نصب تازه** است؛ نصب قبلی Matrix یا فایل‌های همان مسیر رو عمداً بازنویسی نمی‌کنه.

## چند نکته خیلی مهم درباره امنیت و حریم خصوصی 🔐

- پنل `admin` در این نسخه **روی اینترنت عمومی قابل دسترسه**؛ ورود مدیر رو امن نگه دار و بعداً دسترسی پنل رو با VPN یا محدودسازی IP ببند. نصب‌کننده به‌طور خودکار این کار رو انجام نمی‌ده.
- نصب‌کننده **تنظیمات SSH یا فایروال رو به‌صورت تهاجمی تغییر نمی‌ده** تا از VPS بیرون نیفتی. اگه UFW از قبل فعال باشه، پورت‌های ضروری وب و تماس رو اجازه می‌ده. Docker می‌تونه بعضی قوانین معمول UFW رو دور بزنه؛ قوانین پنل VPS رو هم بررسی کن.
- برای پیام‌های واقعاً خصوصی، وضعیت **رمزگذاری سرتاسری (E2EE)** اتاق‌ها رو داخل کلاینت بررسی کن و کلید بازیابی حساب رو نگه دار. صرف نصب Matrix به معنی رمزگذاری سرتاسری همه اتاق‌ها و فایل‌ها نیست.
- **بکاپ رمزگذاری‌شده بیرون از VPS** از PostgreSQL، پوشه `synapse-data` (شامل کلید امضای سرور)، فایل‌های رسانه و پوشه `rtc` لازم داری. این نسخه هنوز بکاپ خودکار نمی‌سازه.
- اگر سرور عمومی است، قبل از استفاده جدی به‌روزرسانی نسخه‌های Docker و امنیت پنل مدیریت رو بررسی کن. `latest` برای بعضی ایمیج‌ها در این نسخه باقی مونده؛ برای تولید جدی بهتره نسخه یا Digest ثابت استفاده بشه.
- محدودسازی نرخ درخواست‌ها، HTTPS، دسترسی کاربران و سیاست نگهداری داده‌ها باید متناسب با استفاده‌ات بازبینی بشن.

## دستورهای دم‌دستی

دیدن وضعیت سرویس‌ها:

```bash
cd /opt/install-matrix && sudo docker compose ps
```

دیدن خطاهای Synapse:

```bash
cd /opt/install-matrix && sudo docker compose logs --tail=100 synapse
```

بررسی آدرس‌های سایت:

```bash
curl -I https://chat.mychat.ir
curl -i https://call.mychat.ir/livekit/jwt/healthz
```

**فایل‌های نصب کجا می‌رن؟** داخل `/opt/install-matrix`. فایل‌های `.env`، `rtc/livekit.env`، `rtc/livekit.yaml`، `synapse-data/homeserver.yaml` و فایل ثبت Application Service شامل رمز/توکن‌اند؛ برای هیچ‌کس نفرست و توی GitHub آپلود نکن.

**اگه نصب وسط کار خطا داد:** خروجی خطا رو بررسی کن؛ اسکریپت عمداً نصب نیمه‌کاره یا موجود رو خودکار پاک و بازنویسی نمی‌کنه. قبل از حذف هر فایلی مطمئن شو دیتابیس و کلیدهای مهمت داخلش نیست.
